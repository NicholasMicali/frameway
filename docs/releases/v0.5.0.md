# Frameway 0.5.0 — release candidate

Prepared for review; not yet published to GitHub Releases or the Chrome Web Store. The current Store installation remains on its published version until the owner submits and publishes the update.

Frameway 0.5 adds more polished walkthrough outputs and a clearer path from recording to sharing, while keeping projects, editing, and exports local.

## What's new since 0.4.0

- Animated hotspots, cards, and additional slide elements: arrows, generic cards, tips, information, and warnings. Optional elements supplement the primary next-step action.
- Local video export that advances through image slides and plays video segments.
- Optional presentation frames with background, spacing, corner, and shadow choices.
- Eleven bundled background tracks, uploaded MP3/WAV/OGG audio, volume controls, and viewer mute. Music travels with supported exports; required artist credits are included.
- Four bundled fonts, clearer project settings, alphabetical soundtrack selection, and a more compact recording popup.
- A refreshed Library with use cases, team-sharing guidance, and reduced-motion-aware visual feedback.
- Share shows the generated filename and file size, with recipient instructions for HTML, editable project files, and embeds.
- More consistent typography, presentation, and soundtrack volume across editor, preview, and exports; timeline ruler overflow fixed.

No accounts, project hosting, cloud sync, analytics, AI, or new extension permissions are introduced. Tab recording still creates click steps automatically; screen/window recording uses manually marked or inserted screenshot steps. Capture is silent; background music is separate from recording audio.

## Install and update

The [Chrome Web Store](https://chromewebstore.google.com/detail/dpfkfbpolahiofedbdebdjmpjfphkjge) remains the recommended installation path. Version 0.5.0 will arrive there only after submission, review, and publication on the existing item.

For candidate testing, use `release/frameway-extension-v0.5.0.zip` and the adjacent SHA-256 file. Extract to a permanent folder, then load the folder containing `manifest.json` using Load unpacked at `chrome://extensions`. Back up projects before changing installations. Reload an existing unpacked installation after replacing files in the same folder.

Store, unpacked, and localhost installations can have separate libraries. Transfer editable `.frameway.zip` files using Share → Download project and Library → Options → Import projects. An HTML export is for viewing, not restoring an editable project.

## Compatibility and limits

Older projects remain supported. Use 0.5.0 on both sides when exchanging projects containing new elements, fonts, framing, or music. Older versions may reject new settings.

Interactive HTML, embed packages, and editable projects include original recording assets. Playback trimming is not permanent redaction. Review the full source recording before sharing these files. Video exports render the playback sequence but are not a substitute for a reviewed redaction workflow.

Keep backups outside the extension. Browser storage is not durable backup storage. Recipients edit independent project copies; changes are not synchronized. Uploaded music must be audio you have permission to distribute.
