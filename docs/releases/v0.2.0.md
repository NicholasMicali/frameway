# Frameway 0.2.0 beta

A simpler path from recording to sharing, with better tools for returning to your work. Frameway remains a local tool with no accounts, backend, or managed hosting.

## What changed

- **Open without recording:** the Chrome toolbar menu now offers Open Frameway, Record this tab, and Stop recording. Includes a new blue extension icon.
- **A clearer library:** updated onboarding, search, sorting, project menus, and a project switcher with Library navigation.
- **Make a copy:** create an independently saved walkthrough from the library’s three-dot menu. Edit or delete either version without affecting the other.
- **Share:** a larger dialog explains HTML sharing, HTML/React website embeds, and editable project backups, with download instructions and error feedback.
- **Storage & backups:** review local usage, track backup exports, delete projects, and recover from save failures.
- Responsive layout and keyboard-accessibility improvements, plus aligned Share button text and icon.

## Install or update

1. Download **frameway-extension-v0.2.0.zip** from Assets below, not a source-code archive. The `.sha256` file contains its checksum.
2. Extract the ZIP into a permanent folder (Windows: **Extract All**).
3. In Chrome, open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked**. Select the folder containing `manifest.json`.
4. Pin Frameway. Click its icon and choose **Open Frameway** to browse projects, or **Record this tab** to record a workflow. Choose **Stop recording** to open the editor.

**Before updating, save editable backups of important projects:** open a project and choose **Share → Export project backup** (the old version labels this **Export / Download → Export project**). Keep the `.frameway.zip` files outside the extension folder.

To update an existing unpacked installation, replace the contents of its existing folder with the extracted package, click **Reload** on its Chrome extensions card, and reopen Frameway. Keep the folder at the same path. If you load from a new folder or use another Chrome profile, restore your backups with **Options → Import project backup**. HTML sharing files are for viewing and cannot restore editable projects.

## Validation and beta limits

Build/model checks run on Windows, macOS, and Linux. Chromium workflows cover recording, editing, offline exports, backups, storage failures, and project-copy isolation. The maintainer tested the new sharing and copying workflows; Windows use and HTML sharing were also reported during the previous beta.

Chrome extension capture is limited to one tab’s top frame, with no audio or automatic desktop click capture. Projects remain in browser storage until exported. Copies may use additional storage. Playback trims do not remove footage: exports retain the complete original recording and are not permanent redaction.

Please report issues with your OS, Chrome version, installation method, and reproduction steps. Keep private recordings and company data out of public issues.
