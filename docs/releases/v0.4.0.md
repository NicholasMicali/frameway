# Frameway 0.4.0 beta — release candidate

Not published yet. This release prepares Frameway for unlisted Chrome Web Store distribution while keeping recording, editing, and exports local.

## Changes

- Refreshed Library with clear capture choices, project menus, and visible sharing/backup help.
- Refined Frameway icon and popup, with consistent recording, paused, and finishing states.
- Shared Radix menus/popovers/tooltips and UI tokens; keyboard navigation and focus restoration checks.
- Optional branded closing slide with editable message and Replay, supported in HTML/embed exports and editable backups.
- Bundled dependency license notices, updated installation/migration guidance, and Store submission materials.

Recording behavior and permissions are unchanged. Record a Chrome tab for automatic click steps, or use Record my screen for desktop/window capture with manually added screenshot steps. Both capture paths remain silent.

## Install/update the candidate

After publication, download `frameway-extension-v0.4.0.zip` from the release Assets. Extract into a permanent folder and load the folder containing `manifest.json` at `chrome://extensions` with Developer mode enabled. For an existing unpacked installation, back up first, replace files in the same folder, Reload, and reopen Frameway.

A future Store installation may have a different extension identity. Export editable `.frameway.zip` backups from the old installation and import them into the new one before removing the old installation. HTML exports are for viewing, not restoring editable projects.

## Compatibility and limits

Older backups still import. Backups containing closing slides require v0.4.0 or newer. Existing walkthroughs are unchanged until a closing slide is added.

Browser-local storage still needs backups. Playback trimming is not permanent redaction: exports include original recording assets. No narration, AI, cloud hosting, or new capture modes were added. Store availability is pending owner approval and Chrome review; there is no live Store link yet.

Validation and remaining native-device checks are tracked in the release preparation PR and [Store readiness checklist](../STORE-READINESS.md).
