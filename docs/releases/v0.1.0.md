# Frameway 0.1.0 beta

Record a browser workflow, edit screenshot and video steps, and send an interactive walkthrough as an HTML file or embed it on your own site. Frameway runs locally, without accounts, a backend, or managed hosting.

## Install

1. Download **frameway-extension-v0.1.0.zip** from Assets below, not the source-code archive.
2. Unzip it into a permanent folder (Windows: **Extract All**).
3. In Chrome, open `chrome://extensions`, enable **Developer mode**, and click **Load unpacked**.
4. Choose the extracted folder containing `manifest.json`. Pin Frameway, open a web page, and click the extension to start recording. Wait for **REC**, then click it again to stop and open the editor.

Export important projects before replacing or removing an extension. Use **Export project** for an editable `.frameway.zip` backup and **Import** to restore it. Keep the extracted extension folder in place.

## Included

- Automatic click screenshots with video between steps.
- Editable title slides, callouts, spotlights, branding, and custom colors.
- Video trim/split controls, slide actions, and undo/redo.
- Smooth highlight zoom in/out with configurable zoom.
- Interactive HTML downloads, HTML/React embed packages, and editable backups named after your project.

## Validation and beta limits

CI covers macOS, Windows, and Linux builds plus Chromium workflows. The owner reports Windows use, HTML sharing, and export → reinstall → import recovery. Managed Chrome policies, display configurations, and large recordings need broader testing.

Capture is limited to one web tab’s top frame; there is no audio or automatic desktop click capture. Recordings stay in browser storage until exported: keep project backups. Playback trims do not remove original media from exports. Exports include the full source recording.

Please report issues with your OS, Chrome version, installation method, and reproduction steps. Do not include private recordings or company data in public issues. See the repository’s tester guide and TODO list.
