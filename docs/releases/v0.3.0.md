# Frameway 0.3.0 beta

More control over recording, editing, and presenting your walkthroughs. Frameway remains a local tool with no accounts, backend, or required cloud services.

## What changed

- **Pause and resume tab recording:** pause while preparing your next action, then resume the same recording. Paused time and clicks are excluded. Finish recording while paused or recording.
- **Chapters and contents navigation:** organize longer walkthroughs and let viewers navigate their contents.
- **Richer project appearance:** customize colors, typography, title layouts, and title logos with preview and Apply/Cancel controls.
- **Callout formatting:** add basic emphasis and lists, plus explicit external link actions.
- **Better video timeline:** fit and zoom the timeline, navigate the playhead, and scrub more precisely.
- **Editor and library polish:** contextual step settings, library renaming and last-edited sorting, discoverable keyboard shortcuts, and refreshed tester documentation.

## Install or update

1. Download **frameway-extension-v0.3.0.zip** from Assets, not a source-code archive. The `.sha256` file contains its checksum.
2. Extract the ZIP into a permanent folder (Windows: **Extract All**).
3. Open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked**. Select the folder containing `manifest.json`.
4. Pin Frameway. Its toolbar menu opens your library or starts recording the current tab. During capture, use **Pause**, **Resume**, or **Finish recording**.

**Before updating, export editable backups of important projects using Share → Export project backup.** Keep those `.frameway.zip` files outside the extension folder.

For an existing unpacked installation, replace its folder contents with the extracted package, keep the same folder path, click **Reload** on the extension card, and reopen Frameway. If you use a new folder or Chrome profile, restore backups with **Options → Import project backup**. HTML viewing exports cannot restore editable projects.

## Validation and beta limits

The maintainer tested the editing improvements and pause/resume before release preparation. PR #42 passed formatting, lint, cross-platform build/model checks, and Chromium workflows. Release-candidate validation is recorded in the release preparation PR; Windows native-toolbar pause/resume behavior still needs manual confirmation.

Capture remains limited to one tab's top frame, without audio or automatic desktop click capture. Pausing does not provide crash recovery. Projects stay in browser storage until backed up. Playback trims do not remove original footage from exports and are not permanent redaction.

Local read-aloud was explored and deferred after voice-quality review. This release does not add speech synthesis, voiceover recording, or AI integrations. Separate narration can be supplied as part of your surrounding training materials.

Report problems with your OS, Chrome version, installation method, and reproduction steps. Keep private recordings and company data out of public issues.
